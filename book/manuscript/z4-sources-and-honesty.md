## A Note on Sources and Honesty

This book makes two kinds of claim, and they are held to two different standards. It is worth saying
plainly how, so you can hold the book to its own word.

**Claims about what the software does.** Everything in these pages about what ErnosDecent is, what works,
what is partial, and what is not built was checked against the actual code — the source you can read, the
tests it ships, and the running node itself. Where this book says a part works, it works in the code and
its tests; where it says a part is half-built or missing, that is named plainly in Chapter 28, *An Honest
Ledger.* The numbers — seventeen subsystems, a hundred-odd source files, roughly thirty thousand lines,
ninety-odd test files — are counted from the code, not rounded for effect. The earlier project
documentation lagged behind the work; it was corrected to match reality before this book described it. If
you find a claim here that the code does not support, the code is the authority, and the book is wrong.
That is the deal.

**The argument about the world.** Chapter 2 gives the spine of an argument made in full, with dates,
names, and sources, across the six books of *The Last Mind.* That argument is mine. This book presents it
directly, as my documented case — but it does not re-try, in these pages, the specific grave claims those
books make about named, living individuals. Where such claims matter, this book points you to the books
where they are laid out and sourced, so you can examine them at the standard they were written to: the
documented public record, with any inference marked openly as inference. That is not a softening of the
argument. It is leaving the naming where the naming is done, in full, where it can be checked.

And the standard under both is the same one, the only one this whole body of work recognises: not my
authority, not anyone's stamp, not the agreement of any institution — but the record, which is published,
which is free, and which you can check yourself. The arbiter is you.

*Do not believe me. Do not believe them. Become an observer.*

The work is on disk. It runs. Audit it.
